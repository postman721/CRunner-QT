# CRunner-QT

<img width="985" height="457" alt="Image" src="https://github.com/user-attachments/assets/a97f5b34-ae81-4ed5-9b57-48f6abf717f6" />

Lightweight program launcher for Linux written in C++ with Qt 6.

## Dependencies (Debian)

```bash
sudo apt update
sudo apt install -y build-essential qt6-base-dev qt6-base-dev-tools
```

Usage: 		Write your command without arguments: firefox

			Write your command with arguments: firefox google.com
			

Hint. You can use what you want for building: I used Qtcreator.


If you need to move the runner: Press and hold ALT and start the moving.
